# BB_breast-cancer_task1
Heart Disease Prediction Using Machine Learning ❤️

This project is developed as Task 1 of my BrainyBeam Internship. The objective is to load and display a Heart Disease dataset in a Streamlit application without using Pandas built-in file-loading functions.

Task Objective
Load the Heart Disease dataset into a Streamlit application.
Manually parse the dataset file.
Automatically detect the file delimiter.
Display the dataset in an interactive interface.
Implement sorting options.
Implement pagination for dataset records.
Dataset Features

The dataset contains the following attributes:

Age
Sex
Chest Pain Type
Resting Blood Pressure
Serum Cholesterol
Fasting Blood Sugar
Resting ECG Results
Maximum Heart Rate Achieved
Exercise-Induced Angina
Oldpeak
Slope
Number of Major Vessels
Thalassemia
